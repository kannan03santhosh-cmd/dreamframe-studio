# DreamFrame Creative Studio

> A modern photography portfolio website built with React.js.

## 📸 About

**DreamFrame Creative Studio** is a modern and responsive photography portfolio website created to showcase professional photography services and creative work.

The website provides a clean and engaging experience for clients to explore photography services and make enquiries easily.

## ✨ Features

* 📷 Photography Portfolio
* 💍 Wedding Photography
* 🎉 Event Coverage
* 🛍️ Product Photography
* 🎨 Brand Photography
* 📱 Responsive Design
* 💬 WhatsApp Enquiry
* ⚡ Fast and Interactive UI
* 🌐 Modern Website Design

## 🛠️ Technologies Used

* **React.js**
* **JavaScript**
* **HTML5**
* **CSS3**
* **React Router**
* **Node Package Manager (NPM)**

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/kannan03santhosh-cmd/dreamframe-studio.git
```

### Navigate to the Project

```bash
cd dreamframe-studio
```

### Install Dependencies

```bash
npm install
```

### Run the Project

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```
